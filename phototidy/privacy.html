整理照片 · 隐私政策

生效与更新日期：2026年9月24日

本政策适用于 iOS 应用“整理照片”（com.appgg.phototidy）。本版本免费，无账号、广告或应用内购买。开发者不通过本应用收集或上传你的照片、视频或识别出的文字。

照片访问与设备端分析

经你授权后，应用读取可访问照片和视频的画面及必要元数据（例如项目标识、拍摄日期、分辨率、时长、收藏与实况状态），用于查找相似内容、筛选清理候选、展示系统分类和统计可读取文件大小。图像特征、画质与文字线索在设备端处理，不发送至开发者服务器或第三方模型服务。本版本不主动下载 iCloud 原片，未下载的项目可能无法分析。

本地保存的信息

应用在设备上保存分析特征、照片标识、分析进度、推荐原因和你选择保留的候选标识，以支持继续分析及避免重复提示。不持久保存识别出的完整文字或验证码。分析特征缓存不纳入设备备份。卸载应用可移除应用本地数据，不会删除系统相册原片；系统备份由 Apple 和你的设备设置管理。

收藏、删除与 iCloud

你主动收藏时，应用通过系统照片服务修改收藏状态。删除仅在你确认后提交至系统；如使用 iCloud 照片，删除和收藏等变化可能同步至关联设备。删除的照片通常可在系统“最近删除”中按系统期限恢复。应用不能替你清空“最近删除”，也不保证删除后立即释放对应空间。

权限与控制

你可在 iOS 设置的照片权限中选择完全访问、有限访问或撤销授权，也可在应用中选择更多照片。撤销权限后相关功能可能不可用。应用不请求通讯录、麦克风或定位权限，也不使用照片进行身份识别或广告追踪。清理建议可能误判，由你决定是否删除。

第三方、诊断与支持

应用没有第三方统计、广告或开发者远程崩溃上报服务；本地故障日志用于排查错误类别和计数，不记录照片内容、识别文字或照片标识。Apple 的系统服务、诊断和 App Store 数据处理受其政策及你的设置约束。

如你主动邮件联系支持，我们会收到你的邮箱、邮件内容和主动提供的附件，并仅用于回复和处理问题。请勿发送不必要的私人照片、验证码等敏感内容；可通过下方邮箱请求删除支持邮件。使用的邮件服务商按照其政策处理邮件。

本网站

支持与政策页面托管于 GitHub Pages；访问网站时，托管服务可能处理 IP 地址等必要访问日志，受 GitHub 隐私声明约束。本页面不嵌入广告、跟踪脚本或分析工具。
