常见问题

怎么订阅一个网站的 RSS？

点「添加订阅」，直接粘贴网站地址即可（例如 daringfireball.net），不必找出确切的 Feed 链接——Tidings 会自动发现页面里声明的 RSS/Atom 源，并尝试常见的 Feed 路径。当然，如果你已经有了确切的 Feed 地址，直接粘贴它同样可以。Tidings 支持 RSS 2.0、Atom 1.0 以及 RSS 1.0 / RDF 三种格式，会自动识别。

怎么用 OPML 把我在别处的订阅导入进来？

大多数阅读器都支持把订阅列表导出成一个 .opml 文件。拿到这个文件后，在 Tidings 的「设置」里选择「导入 OPML」并选中它，你的订阅源（含文件夹结构）就会一次性导入。反过来，「导出 OPML」可以把当前订阅打包带走，迁移到其它阅读器。

全文搜索能搜到哪些内容？

搜索会同时覆盖文章的标题、摘要、正文和作者，并且忽略变音符号（例如搜 "cafe" 也能匹配到 "café"），方便跨语言查找。它检索的是已经同步到本地的文章，因此即使离线也能搜。

没有网络时还能看文章吗？

可以。Tidings 会把刷新到的文章正文保存在本地，已读 / 未读 / 收藏状态也存在本机，所以离线时照样能浏览和阅读，重启应用后一切照旧。只有「拉取新文章」这一步需要联网。你还可以在「设置」里调整自动刷新的间隔。

简报里的「智能摘要」是怎么回事？需要联网或付费吗？

每日简报默认使用内置的离线摘要，不联网、不花钱、开箱即用。如果你希望摘要更聪明，可以在「设置」里自行填入一个 OpenAI 兼容接口的地址和 API Key（用你自己的服务账号）；填了之后，生成简报时文章文本会发送到你指定的那个接口。这完全是可选项，留空即保持纯离线摘要。你填的地址和 Key 只保存在本机。
