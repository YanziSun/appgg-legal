隐私政策

讯潮 Tidings · 最后更新 2026年10月15日

无账号、无广告、不进行跨应用广告追踪。订阅、文章、已读与收藏状态保存在本机。新增的可选使用统计默认关闭：只有你在设置中主动开启后，才向我们的统计服务发送有限的使用事件和随机安装标识。不开启不影响任何阅读功能。

我们收集什么

应用没有账号系统，无需注册或登录，不要求姓名、邮箱或手机号。我们不向统计服务发送文章标题与正文、订阅源、阅读记录、搜索词、网页地址、文件内容、摘要接口地址、API 密钥或错误详情。

可选使用统计：主动同意后才开启

设置中的「隐私与改进 → 分享匿名使用统计」默认关闭。主动开启后，应用会发送以下数据，用于统计活跃与留存、了解功能使用情况以及发现故障数量：

  • 随机安装标识：应用生成的 UUID，用于区分同一安装的事件；不是广告标识符、硬件序列号或你的账号。它能够关联同一安装的使用事件，因此这些数据是去标识化数据，不是完全不可关联的匿名数据。
  • 有限事件：同意统计、首次允许统计后打开、打开应用、访问首页、访问设置、发生应用错误。错误事件不包含错误文字、堆栈或阅读内容。
  • 必要上下文：随机事件 ID、应用标识、应用版本、iOS 平台及事件时间；打开事件额外包含距首次允许统计后打开的天数（0–36500）。

上述事件通过 HTTPS 发送至我们使用腾讯云 CloudBase 托管的统计接收端（liftoff-d2ghvpdwa7c22b591-1304961438.ap-shanghai.app.tcloudbase.com，中国上海区域）。事件数据表不包含 IP 地址、精确位置、联系人或广告标识符字段。云基础设施仍需处理网络连接必需的技术信息（例如 IP 地址）；这不等于应用将这些信息作为事件属性上报。

这些数据不用于广告、跨应用追踪、出售给数据经纪商或内容个性化，不与订阅、文章或摘要请求拼接。不启用统计时，不创建统计安装标识、不保存统计发送队列，也不向该统计接收端发送事件。

保存期限、撤回与删除

设备上的待发送队列最多保留 100 条事件，事件超过 24 小时后不再发送；失败时进行限速重试。服务端原始事件的清理阈值为 90 天，按该阈值执行清理。该期限不代表关闭开关会立即删除服务端已有事件。

你可以随时关闭统计：应用会停止后续统计，清除本机待发送队列及随机安装标识。已发送或撤回时已到达服务器的事件不能通过该开关撤回。再次开启会生成新的安装标识。本机可能保留首次允许统计后的日期用于计算使用天数；该日期本身不会上传。

如希望查找或删除已发送的数据，请通过文末邮箱联系。由于我们不收集姓名或账号，可能需要可核对的随机安装标识才能定位记录；无法定位时，我们不能承诺按真实身份识别这些事件。请不要为此发送订阅内容、文章、API 密钥或其他敏感信息。

订阅源与网页网络请求

除了上面的可选统计和下面的可选摘要接口，作为 RSS/Atom 阅读器，Tidings 会连接你主动添加的订阅源和你打开的文章网站：

  • 当你粘贴一个网址订阅时，应用会访问该网址以自动发现其 Feed 地址。
  • 刷新时，应用向你已订阅的各个 Feed 的服务器发起请求拉取文章（采用带 ETag / Last-Modified 的条件请求，未更新的源仅返回 304，尽量礼貌而省流）。
  • 在阅读视图中打开文章原文或图片时，会向文章所在站点请求对应的网页与媒体资源。

订阅源请求只携带拉取内容必需的标准 HTTP 信息（如目标地址、User-Agent），不附带统计安装标识或统计事件。请求直接发给这些 Feed/站点，不经我们的统计服务器中转。第三方站点按各自隐私政策处理访问请求。

本地存储

你的订阅列表、文件夹、已下载的文章正文，以及已读 / 未读 / 收藏状态，全部以普通文件（JSON）仅保存在你的设备本地。因此 Tidings 可离线阅读，重启后状态依然保留。卸载应用即会删除这些本地数据。OPML 导入 / 导出文件由你自己选择位置，应用不会私自上传。

可选的「智能简报」摘要（默认关闭）

Tidings 内置一个完全离线的文章摘要功能，默认即可使用，不联网。

如果你想要更好的摘要质量，可以在「设置」里自行填入一个 OpenAI 兼容接口的地址和 API Key。一旦填写，生成简报时应用会把相关文章的标题与正文片段发送到你指定的那个接口以换取一句话摘要。这一行为：

  • 完全可选、默认关闭——不填地址和 Key 就永远只用本地离线摘要；
  • 请求只发往你自己配置的地址，Tidings 不内置、也不指向我们自己的任何服务；
  • 你填入的接口地址与 API Key 只保存在本机，不会被上传到别处；
  • 该接口如何处理收到的文本，取决于你选择的服务商的隐私政策，请自行评估。

第三方

Tidings 不包含广告追踪 SDK。上述可选统计由应用自有代码实现，由腾讯云 CloudBase 提供云基础设施；此外，应用会联系你选择的订阅源、文章站点及你主动配置的摘要服务。我们不向广告网络或数据经纪商共享统计数据。

你的权利

你可以在应用内取消订阅、删除文章、清理收藏，或卸载应用以删除本机数据。可选统计的停止与服务端删除请求按上文处理；卸载应用不会自动删除已发送至服务器的事件。

儿童隐私

Tidings 不面向 13 岁以下儿童设计，也不会有意收集儿童的个人信息。如监护人认为儿童发送了可定位的统计数据，请联系文末邮箱；统计可随时关闭。

English summary

Optional usage analytics is off by default and does not affect reading features. If enabled in Settings, Tidings sends a random installation UUID, event UUID, app identifier/version, iOS platform, event timestamp, and only consent, first-open, app-open, home/settings visits and error-count events. App-open events may include days since first permitted use. No articles, subscriptions, searches, URLs, API keys, error messages or crash logs are included. A persistent random UUID links events from the same installation, so the data is pseudonymous, not fully anonymous.

Our HTTPS collector is hosted on Tencent Cloud CloudBase in Shanghai, China. Data is used for analytics and reliability, not advertising, cross-app tracking or sale to data brokers. The device queue is limited to 100 events and expires after 24 hours; the server cleanup threshold for raw events is 90 days. Turning analytics off clears the local queue and installation UUID and stops future collection; it cannot recall events already received. Re-enabling creates a new UUID. Contact the email below about deletion; without an installation identifier we may be unable to locate records. Feeds and optional user-configured AI summary services receive their own requests separately under their respective policies.
