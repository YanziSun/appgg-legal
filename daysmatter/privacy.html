隐私政策

恋恋日 · 最后更新 2026年9月29日

无账号、无广告追踪。你的昵称、事件、纪念日、回忆文字和照片都存在本机；若你主动开启 iCloud 同步，事件数据通过你自己的 Apple 账户在你的设备间同步。你也可以另行选择开启匿名使用统计；它只发送固定的功能使用事件和随机安装标识，不发送任何情侣内容。

我们收集什么

我们不收集、不上传、也不出售你录入的情侣内容。恋恋日没有账号体系，不集成广告 SDK，也不使用 IDFA。你在 App 里创建的昵称、在一起日期、事件标题、回忆文字和照片都只保存在你的设备上。只有你主动开启下述「匿名使用统计」时，才会向我们的统计服务发送白名单化的功能事件。

可选匿名使用统计

匿名统计默认关闭。只有你在首启说明或「设置 → 隐私与改进」中主动开启后，App 才会发送功能打开、保存、搜索、分享等固定事件，以及 App 版本、平台和本机随机生成的安装标识。部分事件只带是否有照片、是否设置提醒等布尔值，或页面、海报样式等固定枚举。

不会发送昵称、在一起日期、纪念日日期或标题、回忆文字、搜索词、照片、备注、设备广告标识或精确位置。随机安装标识只用于计算同一安装的使用次数，不跨 App 关联，不等同于真实身份。

事件由腾讯云 CloudBase（上海区）接收并存储，不向广告商或数据经纪商出售或共享。原始事件最长保留 90 天。关闭统计后，App 会停止发送，并清除本机待发送事件和随机安装标识；已经送达服务端的匿名事件无法从随机标识反查到你的身份或情侣内容。

本地存储

所有事件数据以 JSON 文件形式保存在 App 的本地容器（App Group 容器，供桌面小组件读取）。照片背景经降采样后存于本地。这些数据随 App 卸载而删除，除下文 iCloud 同步外不会离开你的设备。

iCloud 同步（走 Apple，我们无法访问）

iCloud 同步默认关闭。只有你在「设置」中手动开启后，事件数据才会通过 Apple 的 iCloud 键值存储（NSUbiquitousKeyValueStore）在你登录了同一 Apple 账户的设备间同步。该同步完全由 Apple 的 iCloud 基础设施承载并加密，数据在你自己的 Apple 账户内流转，开发者无法读取、无法访问、也无法干预。照片背景暂不参与同步。如需停止，关闭开关即可；如需删除云端副本，可在 iOS 设置中管理该 App 的 iCloud 数据。

历史上的今天 / 节气与农历（网络请求）

「历史上的今天」功能内置一份离线史料库，离线也可用。当你查看某天详情时，App 会额外向维基百科中文「On This Day」公开接口（zh.wikipedia.org）发起一次只读请求来补充当天的公共历史事件；史料更新源还会从一个公开的 GitHub 数据文件拉取。这些请求只包含查询的月/日（如 06/22），不包含你的事件、身份或任何个人信息；失败时静默忽略，本地数据照常显示。农历、二十四节气均为设备本地离线计算，不联网。

通知

提醒为本地通知（UNUserNotification），由你的设备在指定提前量于上午 9:00 触发，不经过任何服务器。是否授权通知完全由你决定，可随时在 iOS 设置中关闭。

照片与生物识别

选择相册照片作为背景时，仅访问你主动挑选的那张图片，处理后存于本地，不上传。应用锁使用系统的面容 ID / 触控 ID / 设备密码（LocalAuthentication）进行本地校验，App 不接触你的生物特征数据——校验完全在设备的安全隔区内完成。

第三方

除上文所述可选 CloudBase 匿名统计，以及对维基百科和公开 GitHub 数据文件的只读访问外，恋恋日不集成第三方分析、广告或跨 App 追踪 SDK。访问公开站点时适用各自的服务条款，但我们不向其传递你的情侣内容。

你的权利

你的内容始终在你掌控之中：在 App 内可随时编辑或删除任意事件和回忆；关闭 iCloud 同步可停止云端同步；关闭匿名统计可停止发送并删除本机统计标识；卸载 App 会删除全部本地数据。如对匿名统计有疑问，可通过文末邮箱联系我们。

儿童隐私

恋恋日不面向 13 岁以下儿童设计，也不会有意收集儿童的个人信息。匿名统计不包含年龄、姓名或用户录入内容。
