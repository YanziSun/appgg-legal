隐私政策

恋恋日 · 最后更新 2026年10月24日

无账号、无广告追踪。你的昵称、事件、纪念日、回忆文字和照片由你在本机管理；只有你主动分享或开启 iCloud 同步时，才会按你的操作交给系统处理。你可以另行选择开启使用与诊断统计，帮助我们发现不好用、卡顿或保存失败的地方。统计默认关闭，不发送情侣内容。

我们收集什么

我们的统计服务不接收、不出售你录入的情侣内容。恋恋日没有账号体系，不集成广告 SDK，也不使用 IDFA。你在 App 里创建的昵称、在一起日期、事件标题、回忆文字和照片保存在你的设备上；主动发起分享或开启 iCloud 同步时，按本政策对应章节处理。只有你主动开启下述可选统计时，App 才会向我们的服务发送限定类别的使用与诊断事件。

可选使用与诊断统计

App 内的「匿名使用统计」默认关闭。只有你在首启说明或「设置 → 隐私与改进」中主动同意或开启后，App 才会向我们的统计服务发送以下信息。拒绝或关闭不会影响记录、提醒、生成纪念卡等功能。

  • 功能使用：打开 App 或页面、完成或跳过引导、创建或保存记录、使用搜索、切换海报样式、选择照片、开始分享，以及分享或保存成功、取消、失败等固定事件。属性仅包含固定页面或入口、样式、结果，以及是否有照片、心情或提醒等布尔值；不包含搜索词、所选照片或记录内容。
  • 性能：首屏可交互、系统首次绘制、纪念卡生成耗时、卡顿时长和峰值内存使用等分档结果及样本数，例如快、正常、慢或高内存，不上传逐帧轨迹或页面录屏。
  • 错误与稳定性：照片读取、图片生成、相册权限、保存或本地存储失败等固定错误类别、发生环节和是否可恢复；以及 Apple MetricKit 提供的崩溃、卡顿、CPU、磁盘写入或启动诊断的类别与计数。系统诊断可能延迟送达，我们不通过该统计上传原始崩溃报告、调用栈、异常全文或文件路径。
  • 基础信息：App 版本、平台、统计事件发生时间、用于重试去重的随机事件标识，以及本应用随机生成的安装标识；开发和测试事件另有来源标记，以避免混入实际使用统计。

我们只用这些信息分析功能是否好用、哪些步骤容易退出、改进性能并排查错误，不用于广告、跨 App 跟踪或识别你的真实身份。随机安装标识不是 IDFA，也不是设备序列号；它允许我们关联同一安装的多次使用、计算活跃和留存，因此不应理解为每条事件完全无法关联或绝对匿名。

不会发送昵称、在一起日期、纪念日日期或标题、回忆文字、搜索词、照片、备注、设备广告标识、通讯录或精确位置。事件发生时间是操作的时间，不是你填写的纪念日期。

统计通过 HTTPS 传输，由腾讯云 CloudBase（上海区）接收和存储，仅用于上述分析与诊断，不向广告商或数据经纪商出售或共享。网络服务提供方可能按其服务规则处理维持传输、安全和运维所必需的网络信息；本应用的统计事件不包含原始 IP 地址或定位信息。

原始统计事件最长保留 90 天，到期删除。本地待发送事件最多保留 24 小时；网络失败会有限重试，不影响功能使用。你可随时在「设置 → 隐私与改进」关闭统计，App 会停止新的主动统计发送，并清空本机待发送队列和随机安装标识。已完成发送的事件不会因关闭开关立即从服务端撤回，而会按上述期限到期删除；重新开启后会生成新的随机安装标识。与这些汇总数据有关的请求或疑问，可通过文末邮箱联系我们。

设备上可能保留只含固定错误类别的本地系统日志，用于设备诊断，不包含你的情侣内容。Apple 自身的系统分析与向开发者分享诊断功能由 iOS 设置及 Apple 隐私规则管理；它与我们上述可选统计开关不是同一个功能。

本地存储

你创建的事件和回忆以 JSON 文件形式保存在 App 的本地容器（App Group 容器，供桌面小组件读取），照片经降采样后存于本地。卸载 App 会删除 App 的本地数据；你自行保存到相册、通过系统分享导出或由系统备份保存的副本，需在对应位置另行管理。

iCloud 同步（走 Apple，我们无法访问）

iCloud 同步默认关闭。只有你在「设置」中手动开启后，事件数据才会通过 Apple 的 iCloud 键值存储（NSUbiquitousKeyValueStore）在你登录了同一 Apple 账户的设备间同步。该同步完全由 Apple 的 iCloud 基础设施承载并加密，数据在你自己的 Apple 账户内流转，开发者无法读取、无法访问、也无法干预。照片背景暂不参与同步。如需停止，关闭开关即可；如需删除云端副本，可在 iOS 设置中管理该 App 的 iCloud 数据。

历史上的今天 / 节气与农历（网络请求）

「历史上的今天」功能内置一份离线史料库，离线也可用。当你查看某天详情时，App 会额外向维基百科中文「On This Day」公开接口（zh.wikipedia.org）发起一次只读请求来补充当天的公共历史事件；史料更新源还会从一个公开的 GitHub 数据文件拉取。这些请求只包含查询的月/日（如 06/22），不包含你的事件、身份或任何个人信息；失败时静默忽略，本地数据照常显示。农历、二十四节气均为设备本地离线计算，不联网。

通知

提醒为本地通知（UNUserNotification），由你的设备在指定提前量于上午 9:00 触发，不经过任何服务器。是否授权通知完全由你决定，可随时在 iOS 设置中关闭。

照片与生物识别

选择相册照片作为背景时，仅访问你主动挑选的那张图片，处理后存于本地，不上传。应用锁使用系统的面容 ID / 触控 ID / 设备密码（LocalAuthentication）进行本地校验，App 不接触你的生物特征数据——校验完全在设备的安全隔区内完成。

纪念卡和恋爱月刊在本机生成。主动点「保存」时，会在取得系统相册添加权限后将成图写入相册；主动点「分享」时，会把成图交给 iOS 分享面板，由你选择接收方或其他 App。你主动分享的图片可能包含自行放入的照片、昵称、日期或文字，请在发送前检查。我们的统计服务不会接收这张成图；接收方 App 对分享内容的处理适用其自身隐私政策。

第三方

除上文所述可选 CloudBase 使用与诊断统计，以及对维基百科和公开 GitHub 数据文件的只读访问外，恋恋日不集成第三方分析、广告或跨 App 追踪 SDK。访问公开站点时适用各自的服务条款；这些公共数据请求不携带你的情侣内容。

你的权利

你可在 App 内编辑或删除事件和回忆；关闭 iCloud 同步可停止后续同步；关闭使用统计可停止新的主动统计发送并删除本机统计标识。相册、系统分享或系统备份中的副本需在相应服务中另行管理。如对统计、数据保留或上述处理有疑问，可通过文末邮箱联系我们。

儿童隐私

恋恋日不面向 13 岁以下儿童设计，也不会有意收集儿童的个人信息。匿名统计不包含年龄、姓名或用户录入内容。
