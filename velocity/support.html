Velocity VPN · 技术支持

Velocity VPN 是一款基于开源 sing-box 内核的网络代理客户端，面向开发者与技术用户。它不提供任何服务器——你需要自备节点或订阅。下面是常见问题；如未解决，欢迎随时邮件联系。

常见问题

怎么导入配置或订阅？

Velocity VPN 不自带服务器，需要你自备节点。支持多种导入方式：① 直接粘贴分享链接（vless / ss / trojan / vmess / hysteria2 / tuic / socks 等）；② 扫描二维码；③ 在设置里填入订阅地址，一键解析订阅内的全部节点；④ 导入 Shadowrocket/Surge 的 .conf 或 Clash YAML 订阅，会自动解析出节点、策略组和分流规则。粘贴框还能智能识别单条链接、多条链接、base64 订阅或 .conf 内容。订阅添加后可设置后台自动刷新（约每 6 小时），并展示流量用量与到期时间。

支持哪些协议？

基于 sing-box v1.11 内核，支持 Shadowsocks（含 obfs / v2ray-plugin 插件）、VLESS（含 REALITY、ALPN）、Trojan、VMess、Hysteria2、TUIC，以及 SOCKS5 和 HTTP/HTTPS 代理，并支持 gRPC / WebSocket 传输。手动添加节点表单覆盖全部协议。WireGuard 需重新编译内核后启用。

连不上怎么办？

按以下顺序排查：① 确认你的节点本身可用、未过期，订阅是否需要刷新；② 在节点列表对节点测速，优先用延迟低、可达的节点；③ 检查分流模式（全局 / 规则 / 直连）是否符合预期，必要时切到"全局"测试；④ 打开应用内"连接日志"查看拨号 / DNS / 路由的具体报错；⑤ 用内置的"连通性自检"确认是否真正出网及当前出口 IP / 地区。若仍无法连接，请把连接日志内容邮件发给我们。

你们会记录我的流量或上网记录吗？

不会。Velocity VPN 没有任何"我们的"服务器，流量只在你的设备与你自己配置的服务器之间直接传输，开发者技术上无法看到、读取或记录它。应用不含任何分析、广告或追踪 SDK，也无需注册登录。应用内的连接日志只是保存在你设备本机的诊断文件（自动滚动、可随时清空、永不上传）。详见 隐私政策。

这个 app 提供节点吗？要付费买服务器吗？

不提供。Velocity VPN 是一个纯客户端工具，本身不出售、不内置任何代理服务器或翻墙服务。你需要从你信任的服务商或自建服务器获取节点 / 订阅，再导入本应用使用。你连接的第三方服务器有其各自的隐私政策与服务条款，请自行评估。
